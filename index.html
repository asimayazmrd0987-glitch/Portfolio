⚡ Latest Build02 / SECURITY TOOL

Attack Path Visualizer

An open-source tool that turns a flat list of vulnerability findings into a graph of predicted attack paths, from internet-facing entry points to crown-jewel assets. Reads an open JSON findings format, auto-layers the graph by attack depth, and walks every entry-to-target route itself, ranking each by a heuristic risk score — no path is hand-picked. Mark a finding remediated and every path through it flips to blocked live, so it's obvious which single fix kills the most risk. The risk formula is documented in the open on purpose: it's a triage heuristic, not a verified exploit chain, and the README says exactly that.

ReactViteGraph AlgorithmsOpen SourceMIT LicenseSecurity
